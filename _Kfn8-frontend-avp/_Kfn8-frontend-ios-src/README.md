# Kfn8 iPhone + iPad app (iOS/iPadOS 27, Swift 6)

A fresh, independent codebase at feature parity with the Vision Pro app (decision D8). Roadmap and status: [../ROADMAP-IOS.md](../ROADMAP-IOS.md).

`project.yml` is the source of truth; `Kfn8iOS.xcodeproj` is generated and ignored.

| Scheme | Targets | Platform |
|---|---|---|
| `Kfn8iOS` | `Kfn8iOS`, `Kfn8iOSUITests`, Kfn8Kit package tests | iOS/iPadOS 27, iPhone + iPad |

## Layout

- `Kfn8iOS/App/`:
  - `AppModel`: navigation, the placement pipeline, undo, A/B flip, inventory, update offers, clearances, lamps;
  - launch options: `--store-path`, `--simulate-lost-alignment`, `--api`, and in Debug only `--catalogue-fixtures` and `--force-revocation-sync`.
- `Kfn8iOS/Room/`:
  - `RoomSession`: the ARKit session or the labelled simulated room, world map and relocalization, touch input, turn buttons;
  - `PlacementScene`: the Design projected onto RealityKit entities;
  - `RoomCapture`: capture mode, planes, room frame, obstacles;
  - `PerformanceMonitor`: the local `Documents/perf-*.json` traces.
- `Kfn8iOS/Catalogue/`: `CatalogueItem`, plus `RemoteCatalogue` (search, filter, paging, verified downloads remembered across launches, revocation, update offers).
- `Kfn8iOS/Views/`:
  - `MainView` (Spaces/Rooms and the room detail);
  - `Panels` (Designs, Inventory, Catalogue);
  - `RoomARScreen` (full-screen room view, panel, photo);
  - `PreviewSheet`.
- `Kfn8iOS/Theme/`: the Showroom palette and fonts, `AdaptiveStack` (rows become columns at accessibility text sizes).
- `Kfn8iOS/Resources/Catalogue/`: the nine conformed fixtures (LOD0 USDZ and contract-v1 manifest each), byte-identical to the backend manifests.
- `Kfn8iOS/Resources/Fonts/`: Fraunces and Hanken Grotesk with their OFL licences.
- `Kfn8iOS/Assets.xcassets/`: the app icon, generated by `../tools/make_app_icon.py --ios-catalog`.
- `Packages/Kfn8Kit/`: this app's own copy of the domain, persistence and catalogue libraries. See its README for its origin and the contract drift check.
- `Kfn8iOSUITests/`: six end-to-end simulator UI tests (room, designs and recovery, online catalogue against generated fixtures, photo, largest text size), run on iPhone and iPad by `ci-ios.sh --with-ui`.

## Quick start

```sh
cd _Kfn8-frontend-avp/_Kfn8-frontend-ios-src
./setup.sh              # checks Xcode 27 + iOS 27 SDK + xcodegen, regenerates Kfn8iOS.xcodeproj, asks before opening Xcode
./setup.sh --no-open    # generate only
./setup.sh --yes        # generate and open without the prompt
```

The script never runs the app, never runs Git and never changes the global `xcode-select`.

## Checks

```sh
_Kfn8-frontend-avp/tools/ci-ios.sh             # contract drift, bundle == manifests, package tests, device + simulator builds
_Kfn8-frontend-avp/tools/ci-ios.sh --with-ui   # plus UI tests on the iPhone 18 Pro and iPad Pro 11-inch (M5) simulators
```

Simulator and host results are never device evidence. The iOS simulator has no ARKit camera, so it shows the labelled simulated room.

## Feasibility probe (I0.S2, nonshipping)

`Kfn8iOSProbe` is a separate app ("Kfn8 Probe") for the device questions in I0.S2: finding a room again, real-world collision, occlusion, lighting and the room photo. Its pure state lives in `Packages/Kfn8iOSProbeCore` (Swift Testing, host). The API choices it relies on are in [../reports/IOS-SDK-API-EVIDENCE.md](../reports/IOS-SDK-API-EVIDENCE.md). The simulator only proves that the probe opens; every result has to come from a physical iPhone or iPad.

### Install on the iPhone (founder)

Either open `Kfn8iOS.xcodeproj` (`./setup.sh --yes`), choose the **Kfn8iOSProbe** scheme and the iPhone, and press ⌘R. Or from the terminal:

```sh
export DEVELOPER_DIR=/Users/coder/Developer/Xcode/Xcode_27_0_0/Xcode_27_0_0.app/Contents/Developer
cd _Kfn8-frontend-avp/_Kfn8-frontend-ios-src && ./setup.sh --no-open
xcodebuild -project Kfn8iOS.xcodeproj -scheme Kfn8iOSProbe -destination 'generic/platform=iOS' \
  -allowProvisioningUpdates -derivedDataPath ~/kfn8-ios-dd build
xcrun devicectl device install app --device <IPHONE-UDID> ~/kfn8-ios-dd/Build/Products/Debug-iphoneos/Kfn8iOSProbe.app
```

The iPhone 13 Pro Max (iOS 27.0, LiDAR) is `00008110-001E55660E8B801E`.

### Protocol (no typing: tap the true observation chips, then one Record button)

Do this in a lit room with a sofa or table and a clear wall. Allow camera access when asked. On **Setup**, wait until Tracking says Normal and Planes lists a floor and a wall.

1. **Find** (T3):
   1. Aim the ring at the floor and tap **Place marker**. A brass cone appears.
   2. Walk slowly around the room until Mapping says *Mapped*, then tap **Save room map**.
   3. Swipe the probe away in the app switcher, reopen it, stand anywhere in the same room and tap **Find room**. Note the time shown. Chips, then Record.
   4. Repeat **Find room** in a *different* room. Chips, then Record.
2. **Collide** (T4):
   1. Aim at open floor and tap **Place box**. With tolerance should say *Clear*. Full size will probably say *Touching*, which is the Vision Pro bug the tolerance fixes.
   2. Drag the box, or use Left/Right/Away/Closer, into a sofa or table until it turns see-through. Chips, then Record.
3. **Occlude** (T4): put the box behind real furniture. Look while standing still, then while walking and turning. Have someone walk in front of it. Try the two switches. Chips, then Record.
4. **Light** (T5):
   1. Aim at a wall and tap **Place lamp**.
   2. Toggle **Lamp on/off**. Raise the intensity if it's faint.
   3. Compare with **Room mesh receives virtual light** off and on.
   4. Screenshot with the lamp on and with it off (side button + volume up). Chips, then Record.
5. **Photo** (T6):
   1. Turn on the consent switch and tap **Capture photo**, allowing "Add to Photos" if asked.
   2. Open the Photos app and look at the picture. Chips, then Record.
6. Tell the agent you're done. The evidence file is pulled from the phone with:

```sh
xcrun devicectl device copy from --device <IPHONE-UDID> --domain-type appDataContainer \
  --domain-identifier com.appliaison.kfn8.ios.probe --source Documents/IOS-PROBE-EVIDENCE.json --destination ./IOS-PROBE-EVIDENCE.json
```

Accessibility checks to fold in: VoiceOver reaches every button and chip, and the largest text size doesn't hide controls.
